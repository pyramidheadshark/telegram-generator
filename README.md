# Telegram Generator

Веб-приложение для автоматической генерации поздравительных телеграмм из данных Excel.

## Возможности

- 📊 Загрузка данных из Excel-файлов
- 📝 Генерация Word-документов по шаблону
- 🔤 Автоматическое склонение ФИО и должностей (персональное обращение)
- 🎯 Визуальный предпросмотр результатов
- 📦 Скачивание архива готовых документов

## Быстрый старт

### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/pyramidheadshark/telegram-generator.git
cd telegram-generator

# Установить зависимости
uv sync
```

### Запуск

```bash
# Локальный сервер
make run

# С туннелем для внешнего доступа
cp .env.example .env
# Отредактировать .env, указав TUNA_TOKEN
make serve
```

Приложение будет доступно по адресу: `https://telegram-generator.ru.tuna.am`

## Использование

### 1. Подготовка данных

Скачайте шаблон Excel и заполните колонки:

| Организация | ФИО | Должность | Адрес | Ответственный |
|-------------|-----|-----------|-------|---------------|

**Пример:**
```
ГОСКОРПОРАЦИЯ «РОСКОСМОС» | Баканов Дмитрий Владимирович | Генеральный директор | 107996, Г. МОСКВА, УЛ. ЩЕПКИНА, Д. 42 | Иванов И.И.
```

### 2. Подготовка шаблона Word

Скачайте пример шаблона и используйте метки:

| Метка | Описание | Пример результата |
|-------|----------|-------------------|
| `{{адрес}}` | Адрес получателя | 107996, Г. МОСКВА, УЛ. ЩЕПКИНА, Д. 42 |
| `{{организация}}` | Название организации | ГОСКОРПОРАЦИЯ «РОСКОСМОС» |
| `{{должность_дат}}` | Должность в дательном падеже | ГЕНЕРАЛЬНОМУ ДИРЕКТОРУ |
| `{{фио_дат}}` | ФИО в дательном падеже | БАКАНОВУ ДМИТРИЮ ВЛАДИМИРОВИЧУ |
| `{{имя_отчество}}` | Имя и отчество для приветствия | ДМИТРИЙ ВЛАДИМИРОВИЧ |
| `{{уважаемый}}` | Приветствие с учётом пола | УВАЖАЕМЫЙ / УВАЖАЕМАЯ |

### 3. Генерация

1. Загрузите Excel-файл с данными
2. Загрузите Word-шаблон
3. Проверьте предпросмотр
4. Нажмите "Сгенерировать"
5. Скачайте ZIP-архив с документами

## Технологии

- **Backend:** FastAPI, python-docx, openpyxl
- **Frontend:** HTMX, Tailwind CSS
- **NLP:** pytrovich (склонение имён), pymorphy3 (склонение должностей)
- **Туннель:** tuna.am

## Требования

- Python 3.12+
- LibreOffice (для предпросмотра) — опционально
